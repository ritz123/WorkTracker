Privacy

The app writes the week to ~/.weekly-tracker on the computer that runs it. It does not send that file anywhere. The in-app update check asks GitHub whether a newer release tag exists.

This site is static and keeps no account. It loads Google Tag Manager container GTM-MF9FCF3N, which sets a cookie and sends the page view to Google Analytics measurement ID G-CKLZRV5K84.
